# Student Performance Analytics System

A Python-based data analysis project that reads student records, processes academic performance using NumPy and Pandas, and generates meaningful results such as total/average marks, grades, pass/fail status, and top performers.

## Project Files
- `main.py`: Main program to run the data analysis and display results.
- `student_data.csv`: Dataset containing student records, marks, and attendance.
- `Project_Documentation and Output ScreenShot.pdf`: Detailed documentation, method explanations, and final output screenshots.
- `README.md`: Project summary and run instructions.

## Technologies Used
- Python
- NumPy
- Pandas
